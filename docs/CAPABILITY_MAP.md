### Qué hace la búsqueda general

`Ctrl+K` busca proyectos, chats y conversaciones por campos identificadores mediante consultas SQL `LIKE`. En conversaciones puede mostrar un fragmento del resumen; no busca el texto de todo el historial ni el contenido de archivos. Para eso se usan FTS5 de resúmenes, `cbm_query` o las herramientas de archivos, según la fuente. Consulta la [implementación de búsqueda global](../mcp-server/src/relay/db_conversations.py#L12-L46) y la [interfaz administrativa](ADMIN_UI.md) para ubicar Indexación, Diagramas y Chat.

### Alcance en una frase

Relay **indexa repositorios elegibles con CBM para consultar su grafo de código**, mantiene **FTS5 sobre resúmenes compactados** y ofrece **lectura bajo demanda** de archivos, skills, SQL y adjuntos explícitos. Cada vía tiene sus propios disparadores, límites y dependencias; ninguna significa que el modelo reciba automáticamente todo el repositorio, todas las conversaciones o todos los datos conectados.
