# Servidor Relay

El paquete Python sirve la API y el workspace web. Consulta el
[README principal](../README.md), la [instalación](../docs/SETUP.md) y la
[API](../docs/API.md).

Instalación editable desde esta carpeta: `python -m pip install -e .`.
Para desarrollo: `python -m pip install -e '.[dev]'`.
Ejecuta las pruebas desde la raíz del repositorio, donde vive `pytest.ini`.
